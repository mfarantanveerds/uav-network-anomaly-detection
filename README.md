# Network Anomaly Detection in UAV Swarms

An end-to-end machine learning framework designed to detect cybersecurity threats and anomalous behavior in Unmanned Aerial Vehicle (UAV) swarm networks.

## Overview
Securing multi-node communication in UAV swarms against cyber-threats is critical for operational safety. This project implements a **Spatio-Temporal Graph Transformer (ST-GT)** framework that models both spatial node interactions and temporal telemetry data across the network.

## Key Highlights
* **Data Processing:** Cleaned and structured spatio-temporal telemetry metrics for dynamic graph modeling.
* **Model Architecture:** Implemented a Transformer-based architecture to classify multiple attack vectors.
* **Results:** Achieved **96.86% multi-class classification accuracy** in threat detection.

## Tech Stack
* **Language:** Python
* **Libraries:** PyTorch, NumPy, pandas, scikit-learn, Matplotlib
